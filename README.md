# UmaRU для Windows

Русский перевод японской Steam-версии Umamusume: Pretty Derby.

**[Скачать установщик для Windows](https://github.com/kapitanzet3-a11y/UmaRU-Updates/releases/latest/download/UmaRU-Setup.exe)**

1. Закройте игру, запустите `UmaRU-Setup.exe` и выберите полный или облегчённый перевод.
2. Откройте ярлык **«Играть на русском (Uma RU)»**. При первом запуске мастеру потребуется интернет. На чистой установке игры нажмите **«Установить русификатор»**. Если перевод уже установлен, мастер сможет использовать подходящие файлы с компьютера.
3. В дальнейшем запускайте игру этим же ярлыком. Когда выходит новый перевод, мастер сам находит его, скачивает и устанавливает перед запуском игры. Скачивать установщик повторно для обновления перевода не нужно.

Если сейчас нет интернета, можно продолжить с ранее установленным переводом. Для ручной проверки откройте **Uma RU Player** и нажмите **«Обновления перевода»**.

## Как обновить сам лаунчер

С версии 1.3 лаунчер при каждом запуске сам проверяет, не вышла ли новая версия. Если вышла, перед запуском игры появится окно с описанием изменений. **«Скачать и установить»** откроет мастер установки после проверки файла. **«Позже»** запустит игру с вашей версией и не будет напоминать об этой версии три дня. Проверить вручную можно в **Uma RU Player** кнопкой **«Обновления лаунчера…»**. Автоматические обновления перевода работают при любом выборе.

Если у вас версия 1.2, один раз откройте **Uma RU Player** из меню «Пуск» и нажмите **«Обновления лаунчера…»**. Если у вас версия 1.1, один раз запустите новый установщик по ссылке вверху и установите его поверх прежнего. Выбранный вариант перевода сохранится.
