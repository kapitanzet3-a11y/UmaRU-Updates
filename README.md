# UmaRU для Windows

Русский перевод японской Steam-версии Umamusume: Pretty Derby.

**[Скачать установщик для Windows](https://github.com/kapitanzet3-a11y/UmaRU-Updates/releases/latest/download/UmaRU-Setup.exe)**

1. Закройте игру, запустите `UmaRU-Setup.exe` и выберите полный или облегчённый перевод.
2. Откройте ярлык **«Играть на русском (Uma RU)»**. При первом запуске мастеру потребуется интернет. Если перевод уже установлен, мастер сможет использовать подходящие файлы с компьютера.
3. В дальнейшем запускайте игру этим же ярлыком. Когда выходит новый перевод, мастер сам находит его, скачивает и устанавливает перед запуском игры. Скачивать установщик повторно для обновления перевода не нужно.

Если сейчас нет интернета, можно продолжить с ранее установленным переводом. Для ручной проверки откройте **Uma RU Player** и нажмите **«Проверить обновления»**.

[Все выпуски](https://github.com/kapitanzet3-a11y/UmaRU-Updates/releases)
